One line, 150 characters, about a small good thing that happened today — the
kind of line that makes a reader smile. A stray cat that never lets anyone
near sat on a shoe this morning and purred, and for one whole minute its
chosen human was the most trusted person in the world.

The entry is the line itself. A judge model compares entries two at a time on
the published brief: on subject first, then warmth, then surprise, then one
concrete detail, then fresh wording. The warmest, most surprising line takes
the $5, split over the top 3 places ($2 / $2 / $1).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes `out/entry.txt` with the line. `main.ts` (Node 22, standard
library only, no network) does nothing else, and the output is deterministic:
the same text, byte for byte, on every run.
